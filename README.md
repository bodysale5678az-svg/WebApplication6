# 🎓 Student Management — ASP.NET Core MVC

A web application for managing students, built with **ASP.NET Core MVC** and **Entity Framework Core**.

---

## ✨ Features

- 📋 Full **CRUD** for students
- 🗄️ **EF Core** with SQL Server
- 🎨 Razor views with clean Bootstrap layout

---

## 🏗️ Project Structure

```
WebApplication6/
├── Controllers/   → Home, Student
├── Models/        → Student
├── Data/          → DbContext
└── Views/         → Razor views
```
